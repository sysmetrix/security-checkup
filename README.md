# 에이전트 보안점검 현황 자동화 도구

부천여성청소년재단 내부망 PC의 에이전트 보안점검 결과(Excel)를 직원 명부와 자동으로 대조하고, 부서별 통계 및 취약 현황을 파악하여 보고서 생성을 돕는 웹 기반 자동화 도구입니다.

## 주요 기능

* 자동 매핑 시스템: 보안점검 결과 파일 업로드 시, 직원 명부(이름, IP 등)와 대조하여 기기 소속을 자동으로 연결합니다.
* 수동 검토 및 할당: 자동 연결되지 않은 기기는 직원을 직접 선택하거나, 공용 PC / 기타 기기로 수동 분류할 수 있습니다.
* 사전 매핑 규칙 설정: 코드 수정 없이 이름, IP 기반의 사전 매핑 규칙(중복 스킵 등)을 화면상에서 바로 추가하고 관리할 수 있습니다.
* 직원 명부 관리: 웹 브라우저 내에서 직원 명부를 엑셀로 내보내거나 가져와 최신 상태로 유지할 수 있습니다.
* 다양한 보고서 내보내기:
   * 총괄 보고서: 전체 점검 결과 및 통계를 엑셀 파일로 다운로드합니다.
   * 부서별 보고서: 각 부서별 점검결과, 요약, 조치필요, 취약항목분석이 포함된 개별 엑셀 파일을 압축(ZIP)하여 다운로드합니다.
   * 대시보드 이미지 및 인쇄: 웹 대시보드 화면을 그대로 이미지(PNG)나 PDF 문서로 저장할 수 있습니다.



## 사용 기술

별도의 서버 구축 없이 웹 브라우저 자체에서 모두 동작합니다.

* 화면 구성: HTML5, CSS3, JavaScript
* 활용 라이브러리:
   * SheetJS: 엑셀 파일 읽기 및 쓰기
   * JSZip: 부서별 보고서 ZIP 압축 처리
   * html2canvas 및 jsPDF: 대시보드 화면 캡처 및 PDF 문서 생성



## 사용 방법

1. index.html 파일을 웹 브라우저(Chrome, Edge 권장)에서 실행합니다.
2. 1단계 (파일 업로드): 보안관제 포털에서 다운로드한 원본 엑셀 파일을 업로드합니다.
3. 2단계 (검토 및 할당): 직원 명부와 자동으로 대조된 결과를 확인하고, 할당되지 않은 기기의 소속을 지정합니다.
4. 3단계 (결과 확인 및 내보내기): 부서별 대시보드와 취약 현황을 확인한 뒤, 필요한 형태(총괄 엑셀, 부서별 압축파일, 대시보드 이미지 등)로 결과물을 내려받습니다.

## 관리자 설정

* 화면 우측 상단의 '설정' 메뉴를 통해 직원 명부 엑셀 일괄 업데이트, 수동 매핑 규칙 등록, 클라우드(GitHub Gist) 동기화 관리가 가능합니다.
* 개인정보 보호를 위해 처리된 모든 데이터는 사용자 PC의 브라우저에만 저장되며, 외부 서버로 전송되지 않습니다.
